


### Como utilizar:
1. **Copie o bloco acima** e cole na sua ferramenta ou modelo de linguagem (LLM).
2. Substitua a variável `{SNAPSHOT_ALERTAS}` (dentro da tag `<snapshot_alertas>`) pelo log bruto ou payload enviado pelo seu sistema de monitoramento.
3. O modelo aplicará os **três exemplos como guia estrutural** para padronizar qualquer entrada que receber.

💡 Se quiser, posso acrescentar metadados em **front-matter (YAML)** ou estruturar a documentação deste prompt para salvar no seu repositório de prompts.
